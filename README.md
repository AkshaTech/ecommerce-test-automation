# E-Commerce Test Automation Suite

A professional Selenium WebDriver automation framework for e-commerce 
testing, built with Java, TestNG, and the Page Object Model pattern.

## Target Application
- **URL:** https://awesomeqa.com/ui/index.php?route=common/home
- **Platform:** OpenCart (TheTestingAcademy eCommerce)

## Tech Stack
| Tool | Purpose |
|------|---------|
| Java 11 | Programming language |
| Selenium WebDriver 4.x | Browser automation |
| TestNG | Test runner and assertions |
| Maven | Build tool and dependency management |
| Page Object Model | Design pattern for maintainable tests |
